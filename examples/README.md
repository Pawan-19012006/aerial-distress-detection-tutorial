# Examples

This directory will contain runnable demonstration scripts, end-to-end command-line entry points, and quickstart examples.

## Planned Examples

As implementation progresses through upcoming milestones, runnable examples will be added here, including:

1. **`detect_image.py`**: Running swimmer detection on a single aerial image with visualization overlays.
2. **`track_video.py`**: Processing an aerial video sequence with multi-object tracking and trajectory visualization.
3. **`pipeline_demo.py`**: Executing the integrated pipeline (detection + tracking + distress analysis) and generating structured telemetry outputs.

> **Status:** Runnable examples will be introduced alongside their corresponding source modules as development progresses.
