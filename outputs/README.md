# Outputs Directory

This directory serves as the default storage location for artifacts produced by pipeline runs, examples, and notebooks.

## Typical Contents

- **Visualizations:** Annotated video streams (`.mp4`), bounding box overlays, and track trajectory plots.
- **Structured Data:** Exported prediction logs, track histories, and distress alerts in JSON or CSV formats.
- **Evaluation Reports:** Precision/recall curves, confusion matrices, and benchmark summaries.

> **Note:** All generated run artifacts in this directory are excluded from Git version control by `.gitignore`.
